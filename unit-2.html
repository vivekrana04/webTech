01 • HTML

HTML Lists, Tables and Images

HTML (HyperText Markup Language) is used to define the structure and content of a web page. HTML elements are written using tags.

A. Lists

Lists arrange related items in a readable format. HTML provides three common list types:

Type Tag Purpose
Ordered list <ol > Displays numbered or lettered items.
Unordered list <ul > Displays bullet points.
Description list <dl > Displays terms and their descriptions using <dt > and <dd >.
<h3 >Web Technologies </h3 > <ol > <li >HTML </li > <li >CSS </li > <li >JavaScript </li > </ol > <ul > <li >Chrome </li > <li >Firefox </li > </ul >

B. Tables

HTML tables display data in rows and columns. The <table > element creates a table, <tr > creates a row, <th > creates a heading cell, and <td > creates a data cell.

<table border="1" > <tr ><th >Name </th ><th >Marks </th ></tr > <tr ><td >Aman </td ><td >85 </td ></tr > <tr ><td >Riya </td ><td >91 </td ></tr > </table >

Important attributes include rowspan (merge cells vertically) and colspan (merge cells horizontally). CSS is generally preferred for table borders and presentation.

C. Images

The <img > element embeds an image. It is a void element, so it does not need a closing tag.

<img src="campus.jpg" alt="University campus" width="400" >
  • src: path or URL of the image.
  • alt: alternative text for accessibility or when the image cannot load.
  • width / height: display dimensions.
Use meaningful alt text. It helps screen-reader users understand the image.
02 • HTML FORMS

HTML Forms

Forms collect information from users and send it to a server for processing. Common examples include login pages, registration forms, search boxes and feedback forms.

Important form elements

Element Use
<form > Defines the form.
<input > Accepts text, password, email, number, checkbox, radio, etc.
<label > Provides a text label for a control.
<textarea > Accepts multi-line text.
<select > / <option > Creates a drop-down list.
<button > Creates a clickable button.
<form action="/register" method="post" > <label for="name" >Name:</label > <input type="text" id="name" name="name" required > <label for="email" >Email:</label > <input type="email" id="email" name="email" > <button type="submit" >Register </button > </form >

GET and POST methods

  • GET: sends form data as part of the URL query string. Suitable for retrieving/searching data.
  • POST: sends data in the request body. Commonly used to submit or create data.

The action attribute specifies where the form data is sent, while method specifies how it is sent.

03 • FRAMES

HTML Frames

Frames were used to divide a browser window into multiple independent sections, where each section could display a separate HTML document.

  • <frameset > defined the arrangement of frames in older HTML.
  • <frame > specified the document shown inside a frame.
  • <iframe > embeds another web page or document inside the current page.
<iframe src="https://example.com" title="Example website" width="600" height="300" > </iframe >
The old <frameset > and <frame > elements are obsolete in HTML5. The <iframe > element is still supported for embedding content.
04 • CSS

CSS – Cascading Style Sheets

CSS controls how HTML elements look on a screen or other media. It separates content (HTML) from presentation (CSS), making websites easier to maintain and design consistently.

CSS syntax

selector { property: value; } h1 { color: navy; font-size: 32px; }

Ways to apply CSS

Type Where written Example
Inline Inside an HTML element's style attribute <p style="color:red" >
Internal Inside a <style > element in the page head <style >p{color:red} </style >
External In a separate .css file linked to HTML <link rel="stylesheet" href="style.css" >

Common CSS selectors

  • Element selector: p selects all paragraphs.
  • Class selector: .card selects elements with class="card".
  • ID selector: #header selects the element with id="header".
  • Universal selector: * selects all elements.

CSS box model

Every element can be understood as a rectangular box made of content, padding, border and margin.

Content → Padding → Border → Margin

CSS properties control colour, font, spacing, borders, dimensions, positioning, layout and responsive behaviour.

05 • DYNAMIC HTML

Dynamic HTML (DHTML) with JavaScript

Dynamic HTML is a combination of HTML, CSS, JavaScript and the DOM. It allows a web page to change its content, style or behaviour after it has loaded, often in response to user actions.

HTML

Provides the structure and content.

CSS

Controls the visual appearance.

JavaScript

Adds logic, events and interactivity.

DOM

Provides a programmable representation of the page.

JavaScript example

<p id="message" >Welcome!</p > <button onclick="changeText()" >Click me </button > <script > function changeText() { document.getElementById("message").textContent = "The content has changed!"; } </script >

Events in JavaScript

An event is an action or occurrence that JavaScript can respond to.

  • click – user clicks an element.
  • mouseover – pointer moves over an element.
  • keydown – user presses a keyboard key.
  • submit – a form is submitted.
  • load – a page or resource finishes loading.

JavaScript can validate forms, update text, change CSS styles, show messages, respond to clicks and modify elements without reloading the entire page.

06 • XML

XML – Extensible Markup Language

XML is a markup language designed to store, describe and transport structured data. Unlike HTML, XML does not use a fixed set of presentation tags. Users define tags according to the data.

Example XML document

<student > <name >Vivek Rana </name > <course >B.Tech CSE-DS </course > <semester >5 </semester > </student >

Basic XML rules

  • There must be exactly one root element.
  • Every start tag must have a matching end tag, or be self-closing.
  • Elements must be properly nested.
  • Tag names are case-sensitive.
  • Attribute values must be enclosed in quotes.
  • Special characters such as < and & must be escaped when used as text.
Well-formed XML: an XML document that follows XML's basic syntax rules. Valid XML: a well-formed document that also follows its DTD or XML Schema rules.
07 • DOCUMENT TYPE DEFINITION & SCHEMA

XML DTD and XML Schema

Document Type Definition (DTD)

A DTD defines the legal structure of an XML document. It specifies which elements and attributes may appear and how elements may be arranged.

<!DOCTYPE student [ <!ELEMENT student (name, course) > <!ELEMENT name (#PCDATA) > <!ELEMENT course (#PCDATA) > ] >

A DTD can be internal (written inside the XML document) or external (stored in a separate .dtd file).

XML Schema (XSD)

XML Schema Definition (XSD) describes the structure and data types of XML elements and attributes. It supports stronger data typing and constraints than traditional DTD.

<xs:element name="age" type="xs:positiveInteger"/ >
DTD XML Schema (XSD)
Uses a non-XML syntax. Written using XML syntax.
Limited data-type support. Supports many built-in and custom data types.
Less expressive for data constraints. Supports constraints such as ranges and patterns.
Namespace support is limited. Supports XML namespaces.

XML namespaces

Namespaces help avoid naming conflicts when XML documents combine elements from different vocabularies. A namespace is commonly identified by a URI and declared using xmlns.

<root xmlns:shop="https://example.org/shop" > <shop:item >Notebook </shop:item > </root >
08 • OBJECT MODELS

XML Object Models

An object model represents a document as structured objects that software can access and manipulate. For XML, a parser can expose elements, attributes and text as nodes in a tree-like structure.

  • Document node: represents the complete XML document.
  • Element node: represents an XML element such as <student >.
  • Attribute node: represents an element attribute.
  • Text node: represents the text inside an element.

The Document Object Model (DOM) is a standard programming interface that represents a document as a node tree. Programs can navigate, read, add, change or delete nodes.

09 • PRESENTING & USING XML

Presenting and Using XML

XML stores data and does not define how that data must look on a screen. To present XML, an application can transform or process it into another format.

Common approaches

  • CSS: can apply basic visual formatting to XML elements.
  • XSLT: transforms XML into formats such as HTML, text or another XML structure.
  • Application code: reads XML data and displays it in a website, application or report.

Where XML is used

  • Data exchange between different applications.
  • Configuration files for software.
  • Web services and structured messages.
  • Document formats and data feeds.
  • Storing hierarchical information.
XML data → Parser / Transformation → HTML or Application Output
10 • XML PROCESSORS

XML Processors: DOM and SAX

An XML processor (parser) reads an XML document and makes its information available to an application. Two commonly taught processing models are DOM and SAX.

DOM – Document Object Model

DOM reads the XML document and builds a tree-like structure in memory. The application can move through the tree in different directions and access nodes as needed.

SAX – Simple API for XML

SAX is an event-based, sequential parser. It reads the XML document from beginning to end and reports events such as the start of an element, text content and the end of an element. It generally does not store the entire document tree in memory.

DOM SAX
Tree-based model. Event-based model.
Usually loads the document structure into memory. Processes the document sequentially.
Allows random access and modification of nodes. Primarily reads data as events; no built-in document tree.
Can require more memory for large files. Usually memory-efficient for large documents.
Useful when repeated navigation or editing is needed. Useful for fast, sequential reading of large XML files.

DOM processing flow

XML file → DOM parser → Node tree in memory → Application

SAX processing flow

XML file → SAX parser → Events in sequence → Application handler
Remember: DOM = tree and random access. SAX = events and sequential reading.
