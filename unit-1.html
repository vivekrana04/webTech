01

History of the Internet

From research networks to a global communication system

The Internet is a worldwide system of interconnected computer networks. These networks communicate and exchange data using a common set of rules called the TCP/IP protocol suite.

1969 · ARPANETOne of the earliest packet-switching networks connected research institutions in the United States.
1983 · TCP/IPARPANET adopted TCP/IP, an important milestone in the development of the modern Internet.
1989–1991 · WWWTim Berners-Lee proposed and developed the World Wide Web at CERN.
1993 · MosaicThe Mosaic browser helped make the Web easier to use through a graphical interface.
Late 1990s · GrowthCommercial Internet services and websites expanded rapidly.
Today · Connected worldBroadband, smartphones, cloud computing and connected services are part of everyday life.

Internet vs World Wide Web

InternetWorld Wide Web
A global infrastructure of connected networks.A service that operates using the Internet.
Supports web, email, file transfer, calls and more.Provides linked pages and resources accessed through browsers.
Uses networking protocols such as TCP/IP.Commonly uses HTTP/HTTPS, URLs and HTML.

✦ Exam-ready explanation

The Internet is a global network of interconnected networks that exchange information using TCP/IP. It developed from early research networks such as ARPANET and has grown into a worldwide platform for communication, education, business and information sharing.

02

World Wide Web and HTML

The system of linked resources and the language used to structure web pages

The World Wide Web (WWW) is a collection of interlinked web pages and resources available over the Internet. A user normally accesses these resources through a web browser. Each resource can be identified by a URL (Uniform Resource Locator).

HTML (HyperText Markup Language) is the standard markup language used to define the structure and content of web pages. HTML uses elements, commonly written with opening and closing tags.

Basic HTML page structure

<!DOCTYPE html>
<html lang="en">
<head>
  <title>My First Web Page</title>
</head>
<body>
  <h1>Welcome to the Web</h1>
  <p>This is a simple HTML paragraph.</p>
  <a href="https://example.com">Visit website</a>
</body>
</html>

Important HTML terms

  • Tag: Markup notation such as <p> or <h1>.
  • Element: The complete structure, including its tag and content.
  • Attribute: Additional information inside a start tag, such as href.
  • Hyperlink: A clickable reference that connects one resource to another.
Remember: The Internet is the underlying network. The Web is one service that uses that network. HTML structures web content; CSS styles it and JavaScript can add behaviour.

✦ Exam-ready explanation

The World Wide Web is an information system of interlinked resources accessed through the Internet. HTML is a markup language used to organise web-page content using elements such as headings, paragraphs, links, images and tables.

03

Protocols: HTTP and SMTP

Rules that allow web clients, servers and mail systems to communicate

HTTP — HyperText Transfer Protocol

HTTP is an application-layer protocol used to transfer web resources between a client (such as a browser) and a web server. It follows a request-response model: the client sends a request and the server returns a response.

  • GET: Requests a resource from the server.
  • POST: Sends data to the server, often to submit a form.
  • PUT: Creates or replaces a resource at a specified location.
  • DELETE: Requests deletion of a resource.
ItemMeaning
80Default port commonly used by HTTP.
200 OKRequest was successful.
404 Not FoundThe requested resource was not found.
500 Internal Server ErrorThe server encountered an unexpected condition.

HTTP is described as stateless because each request is handled independently by default. Cookies and sessions are commonly used by web applications to maintain user-related state.

SMTP — Simple Mail Transfer Protocol

SMTP is an application-layer protocol used to send outgoing email. It transfers messages from a mail client to a mail server and between mail servers.

  • Port 25: Commonly used for mail-server-to-mail-server transfer.
  • Port 587: Commonly used for authenticated email submission.
  • SMTP is used for sending mail; POP3 and IMAP are commonly used to retrieve or access received mail.
Sender's mail app→SMTP server→Recipient's mail server

✦ Exam-ready explanation

HTTP transfers web resources through a client-server request-response process. SMTP is used to send and relay outgoing email between mail systems. HTTP commonly uses port 80, while SMTP commonly uses port 25 or 587 for submission.

04

Protocols: POP3, MIME and IMAP

How email is retrieved, synchronised and formatted

POP3 — Post Office Protocol version 3

POP3 is used by an email client to retrieve messages from a mail server. In a typical setup, messages are downloaded to the device. Depending on the settings, the server may delete the downloaded messages or keep a copy.

IMAP — Internet Message Access Protocol

IMAP allows users to access and manage email stored on a mail server. Messages, folders and read/unread status can remain synchronised across multiple devices.

MIME — Multipurpose Internet Mail Extensions

MIME extends the basic email message format so that email can include different content types, such as images, audio, documents and other attachments. MIME headers identify the type and format of message content.

Protocol / StandardMain purposeCommon default port
SMTPSend outgoing email25 (submission commonly 587)
POP3Download/retrieve email110
IMAPAccess and synchronise server-stored email143
MIMEDescribe and encode different email content typesNot a transport protocol / no port

POP3 vs IMAP

POP3IMAP
Usually downloads messages to a device.Usually keeps messages on the server.
Less suitable for synchronising many devices.Suitable for using the same mailbox on multiple devices.
Useful when users want local message copies.Useful when users need folders and message status synchronised.
Easy way to remember: SMTP = Send, POP3 = Download, IMAP = Synchronise/access, MIME = Attachments and media formats.

✦ Exam-ready explanation

POP3 retrieves email by downloading messages from a server. IMAP manages email stored on the server and supports synchronisation across devices. MIME extends email formatting to support attachments and different types of media.

05

Domain Name System (DNS)

The Internet's naming and directory service

DNS is a distributed naming system that translates human-readable domain names, such as www.example.com, into IP addresses that computers use to locate network services.

How DNS lookup works

  1. The browser checks its DNS cache.
  2. If the address is not cached, the device asks a recursive DNS resolver.
  3. The resolver may query a root DNS server to find the relevant top-level domain (TLD) server.
  4. The TLD server points the resolver towards the domain's authoritative name server.
  5. The authoritative server provides the required DNS record, and the result is returned and may be cached.
Browser / device→Recursive resolver→Root server→TLD server→Authoritative DNS

Common DNS records

RecordPurpose
AMaps a domain name to an IPv4 address.
AAAAMaps a domain name to an IPv6 address.
CNAMECreates an alias from one domain name to another.
MXIdentifies mail servers for a domain.
NSIdentifies the authoritative name servers for a domain.

✦ Exam-ready explanation

DNS stands for Domain Name System. It converts domain names into IP addresses so that users can access Internet services using easy-to-remember names instead of numeric addresses. DNS uses a distributed hierarchy of DNS servers and supports records such as A, AAAA, CNAME and MX.

06

Web Browsers

Client software that retrieves and displays web pages

A web browser is application software that allows users to access websites. It sends requests to web servers, receives resources such as HTML, CSS, JavaScript and images, and displays the resulting page.

Main functions

  • Accepts URLs and sends requests to web servers.
  • Processes HTML to build the page structure (DOM).
  • Processes CSS to calculate the visual layout and appearance.
  • Executes JavaScript to support interactive behaviour.
  • Displays text, images, video and other web resources.
  • Provides features such as bookmarks, history, downloads and developer tools.
BrowserRendering engine commonly associated with it
Google ChromeBlink
Microsoft EdgeBlink
Mozilla FirefoxGecko
Apple SafariWebKit
Examples: Google Chrome, Mozilla Firefox, Microsoft Edge, Apple Safari and Opera.

✦ Exam-ready explanation

A web browser is client-side software used to access and display web pages. It communicates with web servers, interprets HTML, applies CSS, executes JavaScript and renders the final page for the user.

07

Web Servers

Systems that receive browser requests and deliver web content

A web server is software, running on a computer, that accepts HTTP/HTTPS requests and sends responses to clients. The term can also refer to the computer or hosting system on which the server software runs.

Types of web content

  • Static content: Stored files such as HTML pages, CSS files, images and documents are delivered to the client.
  • Dynamic content: The server runs application logic or communicates with a database to create a response based on the request.

Examples of web-server software

Server softwareGeneral description
Apache HTTP ServerWidely used open-source web-server software.
NginxWeb server commonly used for serving content and as a reverse proxy.
Microsoft IISWeb-server platform for Windows environments.
Apache TomcatServer environment commonly used for Java web applications and servlets.

Browser and server communication

User enters URL→Browser finds server→HTTP request→Web server→HTTP response→Page displayed

✦ Exam-ready explanation

A web server is a system that receives requests from web clients and returns web resources through HTTP or HTTPS. It can deliver static files directly or generate dynamic responses using server-side programs and databases.

  1. Define the Internet and the World Wide Web.
  2. Write the full forms of HTTP, SMTP, POP3, MIME, IMAP and DNS.
  3. What is HTML? What is a web browser?
  4. List any four common DNS record types.

  1. Explain the important milestones in the history of the Internet.
  2. Explain the purpose of HTTP and SMTP.
  3. Describe the role of MIME in email communication.
  4. Explain how DNS resolves a domain name.
  5. Describe the main functions of a web browser and a web server.

L3 Apply

  1. Choose SMTP, POP3 or IMAP for sending mail, downloading mail and synchronising mail across devices.

  2. Compare POP3 and IMAP.
  3. Differentiate between a web browser and a web server.

  2. Explain why DNS is important for user-friendly Internet access.
