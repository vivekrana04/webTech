Unit 4: Web 2.0, Web 3.0 and Emerging Technologies

Interactive Web, Semantic Web, Web Applications and Modern Computing Technologies

1. Web 2.0: Interactive and Social Web

Web 2.0 refers to the second generation of the World Wide Web, where users can interact, create, share and modify content instead of simply viewing static web pages.

Features of Web 2.0

  • User-generated content.
  • Social networking and communication.
  • Interactive websites.
  • Content sharing and collaboration.
  • Dynamic web pages.
  • Cloud-based services.

Examples

  • Facebook – Social networking.
  • YouTube – Video sharing.
  • Wikipedia – Collaborative information.
  • Instagram – Photo and video sharing.
  • Blogger – Blogging platform.

Web 1.0 vs Web 2.0

Web 1.0 Web 2.0
Read-only web Read-write web
Static websites Dynamic websites
Limited user interaction High user interaction
Content created mainly by website owners Content created by users
Basic information websites Facebook, YouTube

🎯 Exam Booster

Web 2.0 is an interactive and collaborative version of the World Wide Web that allows users to create, share and modify content through blogs, wikis, social networking and other web applications.

2. Blogs, Wikis and Social Networking Sites

A. Blogs

A blog is a website or web page where an individual or organization regularly publishes articles, opinions, news or information.

Features

  • Posts are generally displayed in reverse chronological order.
  • Readers can comment on posts.
  • Supports images, videos and hyperlinks.
  • Content can be updated regularly.

Examples: WordPress, Blogger and Medium.

Advantages

  • Easy information sharing.
  • Supports online learning.
  • Helps in personal branding.
  • Useful for digital marketing.

B. Wikis

A wiki is a collaborative website that allows multiple users to create, edit and organize information.

Features

  • Multiple users can edit content.
  • Supports hyperlinks.
  • Maintains revision history.
  • Encourages collaboration.

Example: Wikipedia.

C. Social Networking Sites

Social networking sites are online platforms that allow people to connect, communicate and share information.

Features

  • User profiles.
  • Friends and followers.
  • Messaging.
  • Content sharing.
  • Groups and communities.

Examples: Facebook, Instagram, LinkedIn and X.

Comparison

Blog Wiki Social Networking
Publishes articles Creates collaborative information Connects people
Usually controlled by an author Multiple editors Multiple users
Comments and discussions Collaborative editing Likes, comments and messages
WordPress Wikipedia Facebook

3. AJAX – Asynchronous JavaScript and XML

AJAX stands for Asynchronous JavaScript and XML. It is a web development technique that allows a webpage to communicate with a server and update specific parts of the page without reloading the entire webpage.

Working of AJAX

User performs an action
↓
JavaScript sends a request
↓
Server processes the request
↓
Server sends response
↓
Webpage updates without full reload

Technologies Used

  • HTML – Page structure.
  • CSS – Styling.
  • JavaScript – Client-side functionality.
  • XMLHttpRequest or Fetch API – Communication.
  • XML or JSON – Data exchange formats.

Example

When you search for a product on an e-commerce website, suggestions appear automatically while typing without refreshing the entire page.

AJAX Example Using Fetch API


fetch("data.php")
    .then(response => response.text())
    .then(data => {

        document.getElementById("result").innerHTML = data;

    });

Advantages

  • Reduces unnecessary page reloads.
  • Improves user experience.
  • Allows asynchronous communication.
  • Can reduce unnecessary data transfer.

Disadvantages

  • Requires JavaScript.
  • Can introduce security risks if poorly implemented.
  • Debugging can be more complex.

🎯 Exam Booster

AJAX allows a webpage to exchange data with a server asynchronously and update selected webpage content without refreshing the complete page.

4. RSS – Really Simple Syndication

RSS stands for Really Simple Syndication. It is a web feed format used to distribute frequently updated content such as news, blogs and articles.

Working of RSS

  1. A website creates an RSS feed.
  2. The feed contains updated content.
  3. An RSS reader checks the feed.
  4. Users receive updates without visiting the website manually.

Example

Suppose you subscribe to a technology news website through an RSS reader. Whenever a new article is published, the reader can display the update.

Advantages

  • Saves time.
  • Provides automatic updates.
  • Collects content from multiple websites.
  • Reduces the need to visit websites individually.

5. Ruby on Rails

Ruby on Rails is an open-source web application development framework written in the Ruby programming language.

It helps developers build web applications quickly using reusable components and predefined structures.

Features

  • MVC architecture.
  • Database integration.
  • Code reusability.
  • Convention over configuration.
  • Rapid application development.

MVC Architecture

MVC stands for Model, View and Controller.

USER
↓
CONTROLLER
↓
MODEL – Data and Database
↓
VIEW – User Interface
Component Function
Model Handles data and database operations.
View Displays information to users.
Controller Handles user requests and connects Model and View.

Example

When a user opens a product page, the Controller receives the request, the Model fetches product details from the database, and the View displays the product information.

6. Open APIs

API stands for Application Programming Interface. It allows two software applications to communicate with each other.

An Open API is an API whose specification is publicly available for developers to use, subject to its access conditions and terms.

Working of an API

Application sends API request
↓
API receives the request
↓
Server processes the request
↓
API returns data
↓
Application displays result

Example

A weather application can use a weather service API to retrieve temperature, humidity and forecast information.

Advantages

  • Integration between applications.
  • Saves development time.
  • Allows data sharing.
  • Supports innovation.

7. Web 3.0 – Semantic Web

In this syllabus, Web 3.0 refers to the Semantic Web, where information is structured and connected in a meaningful way so that machines can better understand the meaning and relationships between data.

Features

  • Semantic understanding.
  • Machine-readable information.
  • Linked data.
  • Intelligent search.
  • Data interoperability.
  • Improved personalization.

Example

Suppose you search for books written by APJ Abdul Kalam. A semantic system can understand the relationship between the person, the author role and the books associated with that person.

Web 1.0 vs Web 2.0 vs Web 3.0

Web 1.0 Web 2.0 Web 3.0
Read-only Read-write Semantic and intelligent
Static pages Interactive applications Machine-understandable data
Limited interaction User participation Meaning-based processing
Basic websites Social platforms Semantic applications
Important Note: Web 3.0 can also refer to decentralized technologies in modern discussions. However, for this syllabus, focus primarily on the Semantic Web.

10. RDF – Resource Description Framework

RDF stands for Resource Description Framework. It is a standard framework used to represent information about resources on the Web in a structured and machine-readable format.

RDF is an important technology of the Semantic Web.

RDF Structure

RDF represents information using triples. A triple consists of three components:

  1. Subject: The resource being described.
  2. Predicate: The relationship or property.
  3. Object: The value or related resource.

Example

Statement: Vivek studies Computer Science.

Component Value
Subject Vivek
Predicate Studies
Object Computer Science
Vivek
↓ studies
Computer Science

Features

  • Represents relationships between resources.
  • Supports machine-readable data.
  • Enables linked data.
  • Helps integrate information from different sources.

🎯 Exam Booster

RDF represents information using Subject–Predicate–Object triples. It provides a structured way to describe resources and relationships on the Semantic Web.

11. Web-Based Information Systems

A Web-Based Information System (WBIS) is an information system that uses web technologies and internet connectivity to collect, process, store and distribute information through a web browser.

Components

  1. Client – User's browser or device.
  2. Web Server – Receives and processes requests.
  3. Application Server – Executes application logic.
  4. Database – Stores information.
  5. Network – Connects the components.

Architecture

USER
↓
WEB BROWSER
↓
WEB SERVER
↓
APPLICATION SERVER
↓
DATABASE

Examples

  • Online banking systems.
  • University management systems.
  • E-commerce websites.
  • Hospital management systems.
  • Online examination portals.

Advantages

  • Access from different locations.
  • Centralized data management.
  • Easy maintenance.
  • Supports multiple users.
  • Reduces software installation requirements.

Disadvantages

12. Search Engines

A search engine is a software system that searches information available on the Internet and displays relevant results according to a user's query.

Examples

  • Google.
  • Bing.
  • DuckDuckGo.
  • Yahoo.

Working of Search Engines

A search engine generally works through three major stages.

1. Crawling

Search engine bots visit webpages and discover new or updated content.

2. Indexing

The discovered information is analyzed and stored in a searchable index.

3. Ranking

When a user searches for something, the search engine ranks relevant pages and displays the results.

Search Engine Architecture

WEB PAGES
↓
WEB CRAWLER
↓
INDEXER
↓
SEARCH INDEX
↓
USER QUERY
↓
RANKING
↓
SEARCH RESULTS

Advantages

  • Fast information retrieval.
  • Easy access to online resources.
  • Supports research and learning.
  • Helps users discover websites.

Limitations

  • May display irrelevant results.
  • Some results may contain misinformation.
  • Search rankings can be manipulated.
  • User privacy can be affected by tracking.

13. Recommender Systems

A recommender system is a software system that suggests products, services, movies, music or other content to users based on their interests, preferences and behavior.

Examples

  • Netflix recommends movies.
  • Amazon recommends products.
  • Spotify recommends music.
  • YouTube recommends videos.

Types of Recommender Systems

1. Content-Based Filtering

Recommends items similar to those a user has previously liked.

Example: If a user watches science-fiction movies, the system recommends other science-fiction movies.

2. Collaborative Filtering

Recommends items based on the preferences or behavior of similar users.

Example: If two users have similar movie preferences, the system may recommend movies liked by one user to the other.

3. Hybrid Filtering

Combines content-based and collaborative filtering.

Comparison

Content-Based Collaborative Hybrid
Uses item features Uses user behavior Uses both
Focuses on individual preferences Focuses on similar users Combines methods
Recommends similar items Can discover new interests Combines recommendation signals

Advantages

  • Personalized experience.
  • Saves user time.
  • Improves customer engagement.
  • Helps businesses increase sales.

Challenges

  • Cold-start problem.
  • Data privacy.
  • Biased recommendations.
  • Large amounts of data may be required.

14. Benefits of Blockchain

Blockchain is a distributed digital ledger technology that records transactions in blocks linked together using cryptographic techniques.

Once information is recorded and confirmed according to the network's rules, changing it is difficult.

How Blockchain Works

  1. A transaction is initiated.
  2. The transaction is broadcast to the network.
  3. Network participants validate the transaction.
  4. Valid transactions are grouped into a block.
  5. The block is added to the blockchain.
  6. The updated ledger is shared across the network.

Blockchain Structure

BLOCK 1
↓
BLOCK 2
↓
BLOCK 3
↓
BLOCK 4

Each block generally contains transaction data, a timestamp and a cryptographic hash. Blocks are linked through cryptographic references.

Benefits

  1. Transparency – Transactions can be visible to permitted participants.
  2. Security – Cryptographic techniques protect records.
  3. Decentralization – No single central authority is necessarily required.
  4. Traceability – Transactions can be tracked.
  5. Data Integrity – Altering historical records is difficult.
  6. Automation – Smart contracts can automate certain operations.

Applications

  • Cryptocurrency.
  • Supply chain management.
  • Digital identity.
  • Financial transactions.
  • Healthcare record management.

Limitations

  • Scalability challenges.
  • Energy consumption in some consensus mechanisms.
  • Regulatory uncertainty.
  • Implementation complexity.

🎯 Exam Booster

Blockchain is a distributed ledger technology that stores transactions in cryptographically linked blocks. Its major benefits include transparency, security, decentralization, traceability and data integrity.

15. Edge Computing

Edge computing is a computing approach in which data is processed closer to the location where it is generated rather than sending all data to a distant centralized cloud server.

Example: Smart Security Camera

Traditional cloud computing:

  1. Camera captures video.
  2. Video is sent to the cloud.
  3. Cloud processes the video.
  4. Result is sent back.

Edge computing:

  1. Camera captures video.
  2. A nearby edge device processes the video.
  3. It detects movement locally.
  4. Only important information may be sent to the cloud.

Architecture

IoT DEVICES
↓
EDGE DEVICE
↓
LOCAL PROCESSING
↓
CLOUD SERVER

Benefits

  • Low latency.
  • Faster response.
  • Reduced bandwidth usage.
  • Better support for real-time applications.
  • Can continue some operations during internet disruptions.

Applications

  • Smart cities.
  • Autonomous vehicles.
  • Industrial IoT.
  • Smart cameras.
  • Healthcare monitoring.

Edge Computing vs Cloud Computing

Edge Computing Cloud Computing
Processes data near the source Processes data in centralized data centres
Low latency for local processing May involve network delay
Reduces data transmission Often requires sending data to cloud
Useful for real-time applications Useful for large-scale storage and processing

16. Dark Mode in Web Development

Dark Mode is a user interface design approach in which the background uses darker colours and text uses lighter colours. It provides an alternative to the traditional light interface.

Features

  • Dark background.
  • Light-coloured text.
  • Reduced screen brightness in many interfaces.
  • User-selectable themes.
  • Improved visual comfort for some users.

Advantages

  • Can reduce perceived brightness in low-light environments.
  • May save battery on OLED displays.
  • Provides an alternative visual theme.
  • Can improve the experience for users who prefer dark interfaces.

Disadvantages

  • Poor contrast can reduce readability.
  • Some images and colours may not look appropriate.
  • Requires additional design and testing.
  • Not every user prefers dark mode.

HTML and CSS Example














Dark Mode Example

Explanation

  • CSS defines the light and dark themes.
  • JavaScript handles the button click.
  • classList.toggle() adds or removes the dark-mode class.
  • The webpage changes its appearance without reloading.

Important CSS Properties


background-color: #121212;
color: white;

These properties define the background and text colours.
